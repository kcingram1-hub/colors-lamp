\# COLORS LAMP Stack Application



\## Description



COLORS is a web application developed as part of the COP 4331 course. The application demonstrates a basic full-stack web application using the LAMP stack.



Users can log in to the application, add colors associated with their account, and search for previously stored colors. The application uses a web frontend that communicates with PHP API endpoints, which interact with a MySQL database.



\## Technologies Used



\- Linux

\- Apache

\- MySQL

\- PHP

\- HTML

\- CSS

\- JavaScript

\- Git and GitHub

\- DigitalOcean
